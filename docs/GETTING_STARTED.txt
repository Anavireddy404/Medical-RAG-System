Issue: "Port 8000 already in use"
Solution:
  lsof -i :8000          (Find what's using it)
  kill -9 <PID>          (Kill the process)
  python3 main.py --port 8001  (Use different port)


Issue: "ModuleNotFoundError: No module named 'fastapi'"
Solution:
  source venv/bin/activate    (Activate virtual environment first!)
  pip install fastapi uvicorn openai


Issue: "OPENAI_API_KEY not found"
Solution:
  1. Check .env file exists:  cat .env
  2. Check key is in .env:    echo $OPENAI_API_KEY
  3. Restart backend after adding key


Issue: "Frontend can't connect to API"
Solution:
  1. Verify backend running:   curl http://localhost:8000/health
  2. Check browser console:    Press F12
  3. Look for CORS errors
  4. Verify API_URL in index.html matches your setup


Issue: "Docker containers won't start"
Solution:
  docker-compose logs api     (Check error messages)
  docker-compose down -v      (Clean up volumes)
  docker-compose up -d        (Start fresh)
